# Sales-Performance-Analysis-and-Business-Insights-Dashboard-Using-Microsoft-Excel
Transforming raw sales data into actionable business intelligence using Microsoft Excel. 
This project demonstrates how Microsoft Excel can be used as a powerful business intelligence tool to analyze sales performance, identify regional and product trends, monitor profitability, and support data-driven decision-making. By integrating data cleaning, advanced Excel functions, Pivot Tables, and interactive dashboards, the analysis provides meaningful insights that help businesses optimize performance and uncover growth opportunities.
