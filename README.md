# Sales Performance Analysis and Business Insights Dashboard Using Microsoft Excel
Sales Performance Analysis and Business Insights Dashboard is a business intelligence project developed using Microsoft Excel to transform raw sales data into meaningful business insights. The project demonstrates how Excel can be leveraged for data cleaning, advanced formulas, Pivot Tables, Pivot Charts, KPI tracking, and interactive dashboard development to analyze sales performance and support data-driven decision-making.

Project Highlights
* Built an interactive sales dashboard using Microsoft Excel.
* Transformed raw sales data into actionable business intelligence through data analysis and visualization.
* Performed data cleaning, validation, and analysis using advanced Excel functions.
* Developed Pivot Tables, Pivot Charts, slicers, and KPI cards for dynamic reporting.
* Analyzed sales trends, regional performance, product category contributions, and profitability.
* Identified consistent business growth with ₹1.01 crore in total sales and ₹40.31 lakh in total profit.
* Evaluated year-over-year performance, with 2024 achieving the highest sales growth.
* Compared regional performance, highlighting the East region as the top performer while identifying opportunities for improvement in the West region.
* Delivered actionable business insights to support strategic planning, performance optimization, and future business growth.
